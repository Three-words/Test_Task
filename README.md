-- В файле Try2 описан класс Window, который отвечает за создание окон проекта (настройка размеров окна, разделение на области, добавление кнопок и полей для ввода)

-- В файле Command описан класс Command, который отвечает за реализацию функционала кнопок (команда для отображения таблицы, удаление таблицы, 
   добавление новой записи и т.д.)
   
-- В файле SQL описан класс SQL,  в котором реализованы SQL запросы

-- Есть еще класс BD, но его добавлять не стала, т.к. там видны параметр подключения к серверу и БД (лучше скорее всего было вынести все эти данные в отдельный файл)
